## 1. Тренировка на своих ошибках — ✅ сделано

Маршруты `/mistakes` (список ошибок) и `/mistakes-exercise` (тренировка), `MistakesController`,
`MistakesService`, `MistakesAiService`.

**Как получилось.**
- У `AiValidationError` появилось поле `Category`. Ошибки хранятся в отдельной таблице как правила
  (`UserMistakePattern`): категория, правило, примеры, число повторений, даты. JSON сообщений не разбирается.
- Ошибки копятся из двух источников: разговоров и перевода предложений (общий `RecordMistakesAsync`).
- За один заход 3 задания (`MistakesExerciseTasksCount`), не 6. ИИ пишет предложение с ошибкой того же
  правила, пользователь исправляет, ИИ проверяет и объясняет.

**Решённые открытые вопросы.**
- *«Проработанная» ошибка.* У правила своя шкала `MistakeProgress`: `New → One → Two → Mastered`. Неверный
  ответ откатывает назад. `Mastered` возвращается на повторение через 30 дней (`MistakeMasteredReviewDays`),
  не больше одного такого повторения за заход. Правило можно пометить `Ignored`, и оно больше не предлагается.
- *Очки.* 3 за верное исправление, 2 с подсказкой. Каждое правило засчитывается не чаще раза в день. Дневного
  лимита нет.
- *Ошибок нет.* Упражнение отдаёт пустой список заданий.

## 2. «Объясни слово» (taboo) — режим А ✅ сделан

**Режим А сделан** (`/taboo-exercise`, `TabooController`, `TabooService`, `TabooAiService`):
- 3 случайных слова One..Three. Модель пишет описание и
  пример с `___`, опираясь на переводы пользователя; сервер отсеивает подсказки, где проговорено слово или его основа.
- Подсказки: пример, затем плитки с буквами слова (общий `LetterHintComponent`, как в переводе слов). Проверка точная, без учёта регистра.
- Очки 3 / 2 / 1 по числу подсказок, 0 за ошибку, без дневного лимита. Прогресс меняется как в переводе слов: +1 / −1.
- Иконка «Taboo» в доке блокируется, если подходящих слов меньше 3.

**Идея.** Игра-угадайка по словам пользователя, в двух режимах.

**Режим А: ИИ объясняет, пользователь угадывает.**
1. Берутся слова со статусом `One..Three`.
2. ИИ описывает слово на изучаемом языке, не называя его и однокоренные слова.
3. Пользователь вводит или произносит слово. Можно попросить подсказку (ещё одно описание, первая буква).

**Режим Б: пользователь объясняет, ИИ угадывает.**
1. Пользователь видит слово (лучше `Three`: проверка, что слово действительно усвоено).
2. Объясняет его голосом, не называя. STT → текст.
3. ИИ пытается угадать. Если угадал — успех; если нет — говорит, чего не хватило.
4. ИИ проверяет, что пользователь не произнёс само слово.

**Что уже есть.** Выбор слов по прогрессу (каскад из `TranslationsWordExerciseService`), TTS/STT, базовый класс
`AiServiceBase`, уровень ученика (`ILanguageSettingsService.GetLevelAsync` + `AiServiceBase.DescribeLevel`) —
им можно подстраивать сложность описаний.

**Что нужно.**
- `ITabooAiService`: `DescribeAsync(word)`, `GuessAsync(explanation, candidates?)`.
- В режиме Б подумать, давать ли ИИ список слов пользователя как варианты: так угадывать проще и честнее.
- Контроллер, компонент с переключателем режима, озвучка описания через TTS.
- `CountAvailableWordsAsync` и флаг `IsAvailable…` в `UserStatisticsService`, если у упражнения будет минимум слов.

**Прогресс и очки.** Двигает прогресс так же, как `TranslationsWord`: угадал → +1, не угадал → −1. Подсказка
уменьшает очки. Режим Б можно оценивать выше, он сложнее.

**Открытые вопросы.**
- Один компонент с двумя режимами или два отдельных упражнения?
- Как засчитывать режим Б, если ИИ не угадал, хотя объяснение было хорошим?

## 3. Аудио-сценка с вопросами — ✅ сделано

Маршрут `/listening-exercise`, `ListeningController`, `ListeningService`, `ListeningAiService`.

**Как получилось.**
- Только английский: голоса Deepgram есть только для него. Для польского иконка в доке неактивна
  (`IsAvailableListeningExercise`).
- Один вызов модели на сценку: тема из фиксированного списка, 2–3 персонажа (имя, пол, голос), 8–12 реплик и
  4 вопроса. До 6 случайных слов ученика `None..Two` вплетаются в диалог, их прогресс не меняется.
- Голоса подбирает общий `VoiceResolver` (вынесен из разговоров).
- Вопросы и подсказки появляются только после первого полного прослушивания, чтобы варианты не подсказывали
  содержание диалога.
- Вопросы — выбор из 3–4 вариантов, у каждого своя кнопка «Check»: на уверенные вопросы можно ответить сразу,
  без подсказок. Варианты перемешивает сервер.
- Сценки не хранятся. Номера верных ответов уходят клиенту в зашифрованном `Key` (ASP.NET Data Protection,
  живёт час). Повторная проверка того же вопроса очков не даёт (`IMemoryCache`).
- Плеер: реплики подряд, пауза, вперёд, скорость 0.75× / 1× / 1.25× / 1.5× / 2× в меню при наведении (`playbackRate` в
  `SpeechService`). Текст скрыт. Подсказки открываются кнопкой помощи: «прослушать заново» (один раз за сценку, потом верный ответ стоит 2 очка) и «Show text» (1 очко). Кнопки «предыдущая реплика» нет, а Play после конца сценки неактивен, чтобы лимит нельзя было обойти.
- Очки за каждый вопрос — по подсказкам, взятым до его проверки: 3 за верный ответ, 2 после повторного прослушивания, 1 с текстом, 0 за ошибку, без дневного лимита. Когда проверены все вопросы, текст открывается,
  фразы из него можно открыть в словаре.

## 4. Перевод предложений со смысловой проверкой — ✅ сделано

Маршрут `/sentence-translation-exercise`, `SentenceTranslationController`, `SentenceTranslationService`,
`SentenceTranslationAiService`.

**Как получилось — главное отличие от плана: упражнение не привязано к словам.**
- Нет целевого слова и каскада по прогрессу. ИИ пишет 3 предложения (`SentenceTranslationTasksCount`) по уровню
  ученика, каждое на случайную тему из фиксированного списка, чтобы заходы не повторялись.
- Прогресс слов не трогает, минимума слов нет — иконка на главной никогда не блокируется.
- К каждому предложению — эталонный перевод и до 4 подсказок (фрагмент + перевод). Подсказки подчёркиваются
  после «Help», каждая открытая до ответа стоит 1 очко.
- Очки 1–4 по оценке модели (с 4 минус одно за каждую ошибку), 0 если смысл неверен. Дневного лимита нет.
- «Don't know» показывает эталон и даёт 0 очков.
- Ошибки идут в упражнение №1, как и планировалось.
- Язык предложений переключается прямо в упражнении; невыполненные задания при этом перезапрашиваются.
- Из текста модели можно выделить слово или фразу и открыть в словаре.

## Общее для всех четырёх

- **Статистика.** Каждое упражнение пишет очки через `TutorContext.GetOrCreateTodayStatisticAsync`. Дневной лимит
  есть только у разговоров (`ConversationMaxDailyPoints` = 25); у перевода предложений и тренировки ошибок его нет.
  Нет его и у Taboo, и у аудио-сценки.
- **Без ключа Anthropic** упражнения должны честно показывать «недоступно», а не начислять очки.
- **Стоимость.** Каждое упражнение — это вызовы модели. Для генерации заданий подойдёт более дешёвая модель, для
  проверки ответов — основная.
- **Уровень ученика.** Любой новый ИИ-сервис, который пишет текст для ученика, берёт уровень на сервере через
  `ILanguageSettingsService.GetLevelAsync`, а не принимает его с фронтенда.
- **Регистрация** новых сервисов — в `AddBusinessServices` / `Ai/ServiceCollectionExtensions.cs`.
